What I did
----------
I added Python for windows
I installed Git for windows: https://git-scm.com/download/win?utm_source=chatgpt.com
Installed VS Code
Linked GitHub account (left bottom Icon it can be seen gerhard-du-toit)
Installed Python Extensions (Extension options are in left side bar)
In GitHub I created a new repository (clicked on +)
  left README off
  left .gitignore off
  left license off
appy.py is my main file and can run it with "py app.py" which starts a process that listens on port 5000
appy.py references a index.html that is in my template folder

Created .github/workflows and in .GitHub/workflows is a python-ci.yml that is the GitHub Actions pipeline which will trigger a pipeline in GitHub. Pipeline has a run-on option. GitHub will start a Ubuntu VM and install dependancies and compile the app.py
Can see pipeline ru in GitHub ACtions
populated a requirements file which is requirements.txt
buld docker file contents and can then build a docker with 
  docker build -t latencymonitor .
Can save docker image as a file etc
  docker save -o latencymonitor.tar latencymonitor
Can then be loaded on another machine
  docker load -i latencymonitor.tar
